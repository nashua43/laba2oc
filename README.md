# Лабораторная работа № 2
## Многопоточное умножение матриц

**Выполнила:** Витухина Анастасия  
**Группа:** ИТ-7-8  
**Язык программирования:** Java

## 1. Назначение проекта

Проект предназначен для реализации и исследования многопоточного умножения матриц. В нём рассматриваются распределение вычислений между потоками, синхронизация общего счётчика прогресса, обмен данными между процессами и влияние способа распределения строк на время выполнения.

## 2. Реализованные возможности

- Умножение прямоугольных матриц несколькими потоками.
- Ручное создание и запуск рабочих потоков.
- Статическое распределение строк результирующей матрицы.
- Отображение прогресса вычислений с использованием атомарного счётчика.
- Генерация исходных матриц в отдельном процессе и передача данных через IPC.
- Компактное ступенчатое хранение нижнетреугольной матрицы.
- Умножение нижнетреугольной матрицы на обычную матрицу.
- Статическое и динамическое распределение строк нижнетреугольной матрицы.
- Проверка параллельных результатов сравнением с последовательным алгоритмом.
- Проведение серий измерений и сохранение результатов в CSV.

## 3. Требования к запуску

Для сборки и запуска необходимы:
- JDK с компилятором `javac`;
- операционная система, поддерживающая запуск Java-приложений и дочерних процессов.

Проект проверялся на **Eclipse Temurin OpenJDK 25.0.4.1 LTS** в **Windows 11**.

Сторонние библиотеки, Maven и Gradle не используются. Среда разработки необязательна: проект можно собрать и запустить из терминала.

Проверить установленные версии Java можно командами:

```powershell
java -version
javac -version
```

## 4. Структура проекта

Основные исходные файлы находятся в каталоге `src/lab2/`:

```text
lab2_java/
├── README.md
├── src/
│   └── lab2/
│       ├── Main.java
│       ├── MatrixMultiplier.java
│       ├── GeneratorProcess.java
│       ├── MatrixIpc.java
│       ├── TriangularMultiplier.java
│       └── Benchmark.java
```

Назначение основных классов:

| Файл | Назначение |
|---|---|
| `Main.java` | Точка входа. Обрабатывает аргументы командной строки и запускает выбранный режим. |
| `MatrixMultiplier.java` | Реализует обычное умножение матриц и последовательную проверку результата. |
| `GeneratorProcess.java` | Дочерний процесс, который генерирует исходные матрицы и передаёт их данные. |
| `MatrixIpc.java` | Запускает дочерний процесс и принимает переданные матрицы через канал. |
| `TriangularMultiplier.java` | Реализует умножение с нижнетреугольной матрицей, её ступенчатое хранение и два способа распределения строк. |
| `Benchmark.java` | Запускает серии измерений и сохраняет экспериментальные результаты. |

## 5. Сборка проекта

Все команды выполняются из корневой папки проекта в Windows PowerShell.

Создайте каталог для скомпилированных файлов:

```powershell
New-Item -ItemType Directory -Force out
```

Скомпилируйте исходный код:

```powershell
javac -encoding UTF-8 -d out (Get-ChildItem src/lab2/*.java).FullName
```

После успешной компиляции `.class`-файлы будут находиться в каталоге `out`.

## 6. Запуск программы

Общий формат запуска:

```powershell
java -cp out lab2.Main РЕЖИМ ПАРАМЕТРЫ
```

### 6.1. Обычное умножение матриц

```powershell
java -cp out lab2.Main multiply n m k T
```

Параметры:
- `n` — количество строк матрицы A;
- `m` — количество столбцов матрицы A и строк матрицы B;
- `k` — количество столбцов матрицы B;
- `T` — количество рабочих потоков.

Пример:

```powershell
java -cp out lab2.Main multiply 7 5 4 3
```

Матрица A имеет размер `7 × 5`, матрица B — `5 × 4`, результат — `7 × 4`.

### 6.2. Генерация матриц отдельным процессом (IPC)

```powershell
java -cp out lab2.Main ipc n m k T
```

Пример:

```powershell
java -cp out lab2.Main ipc 7 5 4 3
```

Основной процесс запускает отдельную JVM с помощью `ProcessBuilder`. Дочерний процесс генерирует матрицы и передаёт их через стандартный поток вывода в бинарном формате. Основной процесс считывает размеры и элементы матриц, после чего выполняет многопоточное умножение.

### 6.3. Нижнетреугольная матрица: статическое распределение

```powershell
java -cp out lab2.Main triangle n T static
```

Пример:

```powershell
java -cp out lab2.Main triangle 7 3 static
```

Строки заранее распределяются между потоками непрерывными блоками.

### 6.4. Нижнетреугольная матрица: динамическое распределение

```powershell
java -cp out lab2.Main triangle n T dynamic
```

Пример:

```powershell
java -cp out lab2.Main triangle 7 3 dynamic
```

В динамическом режиме поток получает следующую свободную строку с помощью атомарного счётчика `AtomicInteger`.

### 6.5. Справка

Для вывода доступных режимов:

```powershell
java -cp out lab2.Main help
```

## 7. Экспериментальные измерения

Класс `Benchmark` предназначен для проведения серий измерений. Эксперименты запускаются отдельно для обычного умножения, нижнетреугольной матрицы и режима IPC.

**Обычное умножение и сравнение времени при разном количестве потоков:**

```powershell
java -cp out lab2.Benchmark
```

**Сравнение статического и динамического распределения строк:**

```powershell
java -cp out lab2.Benchmark triangle
```

**Измерение генерации и передачи матриц отдельным процессом:**

```powershell
java -cp out lab2.Benchmark ipc 12
```

В последней команде `12` — количество потоков, используемое при умножении полученных матриц.

В проведённых экспериментах использовались размеры матриц `500 × 500`, `1500 × 1500` и `3000 × 3000`. Для основных серий выполнялось по пять измерений для каждой проверяемой конфигурации. Перед учитываемыми измерениями выполнялся прогревочный запуск.

При обработке результатов применялось усечённое среднее: минимальное и максимальное значения исключались, остальные три значения усреднялись.

Результаты экспериментов сохраняются в CSV-файлы. Фактические имена и расположение файлов следует проверять по сообщениям программы после завершения запуска.

## 8. Проверка корректности

После параллельного вычисления программа сравнивает полученную матрицу с результатом независимого последовательного умножения.

Проверка предусмотрена для режимов:
- обычного умножения;
- IPC;
- статического умножения с нижнетреугольной матрицей;
- динамического умножения с нижнетреугольной матрицей.

Контрольная сумма выводится как дополнительная характеристика результата и не заменяет поэлементную проверку.
