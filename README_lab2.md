## Назначение программы

Программа предназначена для исследования многопоточного умножения матриц, способов распределения вычислительной нагрузки между потоками и межпроцессного взаимодействия.

Реализованы:
- умножение прямоугольных матриц с использованием нескольких потоков;
- статическое распределение строк результирующей матрицы;
- отображение прогресса вычислений;
- генерация исходных матриц в отдельном процессе и передача данных через канал;
- умножение нижнетреугольной матрицы на обычную матрицу;
- компактное ступенчатое хранение нижнетреугольной матрицы;
- статическое и динамическое распределение строк;
- проверка результатов сравнением с последовательным алгоритмом;
- автоматическое измерение времени и сохранение результатов в CSV.


### Обычное умножение матриц

```bash
java -cp out lab2.Main multiply n m k T
```

Параметры:
- `n` — количество строк матрицы A;
- `m` — количество столбцов матрицы A и строк матрицы B;
- `k` — количество столбцов матрицы B;
- `T` — количество рабочих потоков.

Пример:

```bash
java -cp out lab2.Main multiply 500 400 300 4
```

Матрица A имеет размер 500 × 400, матрица B — 400 × 300, результат C — 500 × 300.

### Генерация матриц отдельным процессом (IPC)

```bash
java -cp out lab2.Main ipc n m k T
```

Пример:

```bash
java -cp out lab2.Main ipc 500 400 300 4
```

В этом режиме родительский процесс запускает отдельную JVM с помощью `ProcessBuilder`. Дочерний процесс `GeneratorProcess` генерирует матрицы A и B и передаёт их родительскому процессу через стандартный поток вывода. Размеры и элементы матриц передаются в бинарном формате.

Стандартный поток ошибок дочернего процесса используется для служебных сообщений, чтобы они не смешивались с передаваемыми данными.

### Нижнетреугольная матрица: статическое распределение

```bash
java -cp out lab2.Main triangle n T static
```

Пример:

```bash
java -cp out lab2.Main triangle 500 4 static
```

Строки результата заранее распределяются между потоками непрерывными блоками.

### Нижнетреугольная матрица: динамическое распределение

```bash
java -cp out lab2.Main triangle n T dynamic
```

Пример:

```bash
java -cp out lab2.Main triangle 500 4 dynamic
```

В динамическом режиме рабочий поток получает следующую строку с помощью атомарного счётчика `AtomicInteger`.

## Описание алгоритмов

### Умножение матриц

Если матрица A имеет размер `n × m`, а матрица B — `m × k`, результат C имеет размер `n × k`.

Элемент результата вычисляется по формуле:

```text
C[i][j] = сумма A[i][p] * B[p][j], p = 0 ... m-1
```

В программе используется ручное умножение с тремя вложенными циклами в порядке `i → p → j`. Матрицы хранятся в двумерных массивах `long[][]` и заполняются случайными целыми числами от 0 до 9.

### Статическое распределение строк

При статическом распределении строки результирующей матрицы заранее делятся на непрерывные блоки. Если количество строк не делится на число потоков, первые потоки получают по одной дополнительной строке.

Каждый поток записывает данные только в назначенные ему строки матрицы C. Поэтому одновременная запись нескольких потоков в одну ячейку не возникает.

### Счётчик прогресса и синхронизация

Для подсчёта завершённых строк используется `AtomicInteger`. После вычисления очередной строки рабочий поток атомарно увеличивает общий счётчик. Главный поток считывает его значение и выводит процент выполнения.

Для ожидания завершения рабочих потоков применяется метод `join()`.

### Межпроцессное взаимодействие

Для обмена данными используется канал между дочерним и родительским процессами. Родительский процесс запускает дочернюю JVM через `ProcessBuilder` и читает её стандартный поток вывода.

Передача выполняется в бинарном формате с использованием `DataOutputStream` и `DataInputStream`. Сначала передаются размеры матриц, затем элементы A и B.

Возможные альтернативные способы межпроцессного взаимодействия:

| Способ | Принцип работы | Особенности |
|---|---|---|
| Каналы (pipe) | Передача последовательности байтов между процессами. | Подходят для потоковой передачи данных; требуется согласованный формат сообщений. |
| Файлы | Один процесс записывает данные в файл, другой считывает их. | Просты для отладки и хранения, но требуют операций с файловой системой. |
| Сетевые сокеты | Обмен данными через сетевое соединение. | Подходят для взаимодействия процессов на разных компьютерах. |
| Отображаемые в память файлы | Несколько процессов отображают один файл в память. | Подходят для больших объёмов данных; требуют синхронизации доступа. |

### Нижнетреугольная матрица

Нижнетреугольная матрица — квадратная матрица, у которой все элементы выше главной диагонали равны нулю.

В программе матрица A хранится в ступенчатом массиве: строка с индексом `i` содержит только `i + 1` элементов. Общее количество хранимых элементов:

```text
n * (n + 1) / 2
```

Таким образом, вместо `n²` элементов полной матрицы сохраняются только элементы нижнего треугольника вместе с главной диагональю.

При вычислении строки `i` достаточно перебирать индекс `p` от 0 до `i`, поскольку элементы выше диагонали равны нулю.

### Динамическое распределение строк

В динамическом режиме потоки получают строки по мере освобождения. Для выдачи очередной строки используется атомарная операция `getAndIncrement()` объекта `AtomicInteger`.

Статическое распределение заранее назначает каждому потоку диапазон строк. Динамическое распределение назначает следующую строку непосредственно во время вычислений.

## Проверка корректности

Для обычного и треугольного умножения реализованы последовательные алгоритмы. После параллельного вычисления программа сравнивает результирующие матрицы поэлементно с результатами последовательного вычисления.

Проверка выполняется в режимах:
- `multiply`;
- `ipc`;
- `triangle` со статическим распределением;
- `triangle` с динамическим распределением.

Контрольная сумма представляет собой сумму всех элементов результирующей матрицы и выводится как дополнительная характеристика результата.

## Автоматическая серия измерений

Для сравнения статического и динамического распределения используется `Benchmark.java`.

Параметры полной серии:
- размеры квадратных матриц: `500 × 500`, `1000 × 1000`, `1500 × 1500`;
- количество повторов для каждой комбинации: 5;
- количество потоков: от 1 до удвоенного количества доступных логических процессоров, а также дополнительные значения, равные четырём и восьми количествам доступных логических процессоров;
- для каждого набора входных матриц выполняются статический и динамический режимы.

Одинаковые входные матрицы используются для обоих способов распределения. Перед измеряемым вычислением выполняется прогревочный запуск, время которого не учитывается. Длительность вычисления измеряется методом `System.nanoTime()`.

### Быстрый запуск

```bash
java -cp out lab2.Benchmark --quick
```

Быстрый режим использует небольшие размеры матриц и два повтора.

### Полный запуск

```bash
java -cp out lab2.Benchmark
```

Полная серия сохраняет результаты в файл `triangle_benchmark.csv`.

В CSV-файл записываются столбцы:

| Столбец | Содержание |
|---|---|
| `size` | Размер стороны квадратной матрицы. |
| `threads` | Количество рабочих потоков. |
| `distribution` | Способ распределения: `static` или `dynamic`. |
| `run` | Номер повтора. |
| `time_seconds` | Время вычисления в секундах. |
| `checksum` | Контрольная сумма результата. |

Для анализа результатов используются ускорение и эффективность:

```text
S(T) = t(1) / t(T)
E(T) = S(T) / T
```

где `t(1)` — время выполнения при одном потоке, `t(T)` — время при T потоках, `S(T)` — ускорение, `E(T)` — эффективность.
